# Logos

- `hms.svg`: Harvard Medical School wordmark, from
  https://en.wikipedia.org/wiki/File:Harvard_Medical_School_seal.svg
  (non-free; trademark of the President and Fellows of Harvard College).
  Used only to identify the research collaboration with the Rajpurkar Lab.
- `hms-dark.svg`: the same file with the dark "HARVARD" text recoloured to
  #ededee and the "MEDICAL SCHOOL" text lightened to #f2687b so both stay
  readable in dark mode.
- `jhu.svg`: Johns Hopkins University wordmark, from
  https://en.wikipedia.org/wiki/File:Johns_Hopkins_University_logo.svg
  (non-free; trademark of The Johns Hopkins University). Used only to
  identify the research collaboration with Prof. Zongwei Zhou.
- `jhu-dark.svg`: the same file recoloured to #ededee (reversed logo) for
  dark mode.
